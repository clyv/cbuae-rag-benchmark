# Sources and reuse terms

Complete this **before making the repository public**. This file is the record
that the corpus was collected lawfully and with attribution.

## Why this exists

Source documents are not committed to this repository; `scripts/download_corpus.py`
fetches them from the publisher at clone time. That keeps the repo small and
avoids a redistribution question. It does not remove the need to check terms.

- **Terms page:** <exact URL of the copyright / terms-of-use / open-data page>
- **Date checked:** <YYYY-MM-DD>

- **Attribution required?:** <yes/no - and if yes, where this repo provides it>
- **Redistribution:** <permitted / not permitted / unclear>
- **Approach taken:** <e.g. fetch-at-clone-time only; no source files committed>

## Open questions

ambiguous about whether regulatory text falls under a general open-data policy,
write that down here instead of proceeding on an assumption.
